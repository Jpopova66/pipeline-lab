# Занятие 1. Зачем запускать проверки локально перед CI?

Локальный прогон даёт обратную связь до `git push`. Я могу сразу исправить ошибки линтера и тестов, а также проверить, что приложение запускается и отвечает по HTTP. CI повторяет эти проверки после пуша в стандартном окружении, чтобы результат был воспроизводимым для всей команды.

При локальном прогоне Ruff не нашёл замечаний, pytest подтвердил прохождение всех трёх тестов, а маршруты `/` и `/health` вернули HTTP 200.
