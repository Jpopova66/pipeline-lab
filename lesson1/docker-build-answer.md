# Занятие 1. Шаг 3. Сборка Docker-образа в CI

- `needs: lint-test` задаёт зависимость между заданиями. Сборка запускается после успешной проверки Ruff и прохождения тестов.
- `github.sha` — полный SHA коммита, для которого запущен workflow. Он передаётся в сборку как `APP_VERSION` и используется в теге образа.
- Тег с SHA помогает найти сборку конкретного коммита и выбрать её для отката. Тег `latest` может со временем указывать на другой образ.

В [прогоне GitHub Actions](https://github.com/Jpopova66/pipeline-lab/actions/runs/45667311530) линтер, тесты и сборка образа прошли успешно. На этом шаге образ собран на раннере. Публикация в GHCR выполняется на следующем этапе.
